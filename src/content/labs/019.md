## 概要

The Movie Database (TMDB) APIを使用してホラー映画の一覧を動的に表示するページです。

## 主な機能

- TMDB APIからホラー映画データを取得
- Fetch APIを使用した非同期データ取得
- ページネーション機能
- レスポンシブグリッドレイアウト
- レーティング制限（PG-12以下）

## 使用技術

- JavaScript (TypeScript)
- Fetch API
- TMDB API
- CSS Grid Layout
